# 饮食原则速览

心衰、水肿和肾功能一起管：严格低盐、严防高钾、控制磷、优质低蛋白、限制液体。

## 五个必须

| 必须 | 限度 | 做法 |
| --- | --- | --- |
| 严格低盐 | 食盐每天不超过 **3 克**（约半个啤酒瓶盖）。水肿明显再收紧。 | 减轻心衰和水肿，也帮助控压。酱油、蚝油、豆瓣酱里的盐都要算进去。 |
| 严防高钾 | 蔬菜焯水后再做，大约能去掉 **30%–50%** 的钾。 | 肾排钾差，高钾可能引起心律失常。**禁用低钠盐**（它是高钾盐）。 |
| 控制磷 | 肉先焯水、弃汤再烹饪，大约能去掉 **30%–50%** 的磷。 | 用来延缓肾性骨病。不吃坚果、动物内脏、加工肉制品、浓汤。 |
| 优质低蛋白 | 每天大约 **0.6 克/公斤** 体重。 | 减轻肾脏负担，同时保住营养。额度留给鸡蛋、牛奶、去皮瘦肉、鱼。按 50 公斤估算，每天大约 **30 克**：1 个鸡蛋 + 1 两瘦肉 + 1 杯牛奶。 |
| 限制液体 | 一般 **1.5–2 升**；水肿明显 **1–1.5 升**。 | 减轻心脏负荷。水、粥、汤、牛奶、水果里的水都算。更精确：当天饮水 ≈ **前一天总尿量 + 500 毫升**。 |

## 推荐吃

**主食**（低蛋白，先保证能量，少消耗自己的肌肉）

米饭、面条、馒头、粉丝、藕粉、马蹄糕。红薯、土豆、莲藕可以部分替代米面。土豆要切丝焯水后再做，用来去钾。

**蛋白质**（额度有限，留给吸收好的）

鸡蛋（尤其蛋清）、牛奶、去皮禽肉、瘦猪肉、鱼肉。每天总量按上表控制，不要超。蛋黄见下方「高磷」，优先吃蛋清。

**蔬菜**（挑低钾的，并且焯水）

白菜、冬瓜、黄瓜、茄子、西葫芦、丝瓜、洋葱、豆芽。切小块，沸水焯 **3–5 分钟**，捞出把汤倒掉，再炒或凉拌。

**水果**（挑低钾的，并且限量）

苹果、梨、西瓜、葡萄、菠萝、草莓。每天一共 **200–350 克**（大约一个中等苹果）。水果里的水计入当天液体。

## 避免吃

**高钾：** 香蕉、橙子、橘子、哈密瓜、猕猴桃、桂圆、没焯水的土豆、菠菜、苋菜、空心菜、菌菇、紫菜、海带，以及低钠盐。

**高磷：** 坚果（核桃、花生等）、动物内脏、蛋黄、加工肉（火腿、腊肉、香肠）、碳酸饮料、浓肉汤、火锅汤。

**高盐：** 咸菜、腌菜、腊味、罐头、方便面，以及酱油、蚝油、豆瓣酱。

## 烹饪：焯、弃、替

- **焯：** 蔬菜切小块，沸水焯烫；肉切小块，先煮一下。
- **弃：** 焯菜的水、煮肉的水全部倒掉。不要拿来做汤，也不要拌饭。
- **替：** 用葱、姜、蒜、香菜、柠檬汁、番茄提味，替代盐和酱油。
