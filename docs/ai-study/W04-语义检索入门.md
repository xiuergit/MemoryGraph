# W04 · 语义检索入门（MemoryGraph 里的 RAG ①）

**本周目标**：在本项目加「照片语义索引」— 每条 JSON 的 scene/tags/objects → Embedding → 向量库。  
**JD 对齐**：RAG 的 Embed + Store + Retrieve（文档 = 一条 photo 记忆）。  
**预计**：6～8h

---

## 设计约定（先读再做）

- **不改动** `photo.v1.json` 字段名
- **不替代** SQLite；向量是 **补充检索**，供模糊问法（「开心玩水」「第一次坐飞机」）
- **建议路径**：
  - 代码：`tools/memory_vectors/main.py` + `hub/shared/vector_search.py`
  - 索引文件：`data/memory_vectors/`（gitignore，可删重建，类似 db sync）

---
